# 王者荣耀/三角洲/和平精英电竞护航游戏俱乐部约玩代练录单报单派单打手接单管理系统

源码获取：ym7k.com/19849/

## 一、技术架构

后端：ThinkPHP + FastAdmin 后台，自带 RBAC 权限、表格导出、消息通知、财务流水；
前端：Uniapp 开发 H5，打手、管理、客服手机直接打开操作，不用下载 APP；
整套系统角色分离，老板、客服、派单员、打手、财务权限独立，数据互不越权。

## 二、核心业务模块

### 1. 游戏与套餐配置（后台）

后台自定义添加游戏：王者荣耀、和平精英、三角洲行动等；
自定义分区、段位、服务类型：代练上分、陪玩护航、车队、陪打、代打、巅峰赛、排位、单子套餐；
设置不同服务标价、打手分成比例、平台 / 俱乐部抽成，支持分段定价。

### 2. 客服录单报单模块

客服接到客户订单后录入订单：选择游戏、区服、段位需求、客户联系方式、订单类型、客户实付金额、约定完成要求、截止时间；
可上传客户截图、需求备注；订单提交进入待派单池；
支持客户订单查单，客户可通过链接查看订单进度。

### 3. 派单管理（派单员）

派单员查看所有待派订单，筛选游戏、段位；
指派给对应打手，发送派单通知；
支持抢单模式：打手大厅自主抢单（两种模式可开关：管理员指派 / 打手抢单）。

### 4. 打手接单端（H5 手机端）

打手登录后看到指派给自己的订单或者抢单大厅；
接单、开始打单、上传进度截图、阶段性汇报；
完成订单后提交完工、上传结单截图，等待客服 / 老板验收；
订单状态流转：待派单 → 已派单 → 接单中 → 待验收 → 已完成 / 售后驳回。

### 5. 售后驳回、补单流程

验收不合格可以驳回订单，填写驳回原因；
打手看到驳回信息，重新补单，形成售后记录，避免扯皮。

### 6. 财务结算 & 分成（核心亮点）

自动计算：客户付款总额、俱乐部抽成、打手佣金；
每一笔订单清晰记录分成；
打手可查看自己全部订单、已结算 / 待结算佣金；
打手在线申请提现，后台财务审核提现；
完整资金流水、提成报表、每日营收统计，支持导出 Excel 对账。

### 7. 打手档案管理

打手资料登记、擅长游戏、擅长段位、打手等级、接单状态、历史完成订单、好评差评、黑名单；
可以限制打手接单权限，违规打手暂停抢单、派单。

### 8. 订单消息通知

订单指派通知、新抢单提醒、验收通知、驳回售后通知、佣金到账通知，支持微信消息提醒。

### 9. 数据统计看板

后台可视化图表：每日订单量、营收总额、打手接单排行、售后率、各类游戏订单占比；
可按时间段、游戏、打手、客服多维度筛选报表导出。

### 10. 权限角色体系

- 超级管理员（老板）：全部权限、查看所有财务数据
- 客服：只能录单、跟进订单、验收
- 派单员：负责分配订单
- 打手：接单、上传进度、查看自己佣金，看不到别人订单和财务
- 财务：审核提现、对账

## 三、订单完整业务流程

客服录入客户订单 → 进入待派单池 → 派单指派 / 打手抢单 → 打手接单开工 → 上传进度截图 → 完工提交验收 → 客服验收通过 → 自动生成打手佣金 → 打手申请提现 → 财务审核打款

## 四、适用场景

✅ 王者荣耀、和平精英、三角洲行动游戏代练工作室
✅ 电竞陪玩、护航车队、游戏俱乐部
✅ 多打手、多客服的规模化接单团队
✅ 工作室内部订单管控、防止飞单、对账混乱

## 五、系统优势

1. 专门针对游戏俱乐部业务，不是通用商城改造，订单流转、分成、抢单贴合代练护航行业；
2. H5 移动端，打手手机随时接单上传截图，电脑后台老板统一管控；
3. 自动算分成，告别手工算提成，减少对账纠纷；
4. 订单全程留痕，截图存档，售后有据可查，防止打手和客户扯皮；
5. 源码可二开，可拓展客户下单自助前台、评价系统、会员套餐、分销拉客户等功能。
